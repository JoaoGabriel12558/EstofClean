# 🧼 EstofClean

Site institucional desenvolvido para apresentar serviços de limpeza de
estofados, como sofás, colchões e interiores de veículos.

O projeto tem como objetivo demonstrar a criação de uma landing page
simples, moderna e responsiva utilizando tecnologias básicas de
front-end.

------------------------------------------------------------------------

## 🚀 Tecnologias utilizadas

-   HTML5\
-   CSS3

------------------------------------------------------------------------

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para fins de aprendizado e prática em
desenvolvimento web, simulando um site real de prestação de serviços.

------------------------------------------------------------------------

## 💻 Funcionalidades

-   Apresentação dos serviços\
-   Layout responsivo\
-   Design simples e intuitivo\
-   Estrutura otimizada para navegação
